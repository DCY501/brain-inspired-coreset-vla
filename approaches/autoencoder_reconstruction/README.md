# 思路三：自监督重建误差采样 (Autoencoder Reconstruction Error Sampling)

> **核心思想**：训练一个轻量自编码器压缩视觉特征。重建误差大的帧 = 模型"看不懂"的帧 = 信息最丰富。模拟大脑对"意外/难预测"刺激分配更多注意力的机制。

---

## 动机

v1.1 冗余分布利用**空间几何**（K-Means 聚类），时序方法利用**动作变化率**。本思路从第三个维度切入——**特征压缩质量**。

核心假设：自编码器能轻松重建的常见视觉状态是冗余的；难以重建的罕见/复杂状态是高价值的。

---

## 算法

### Step 1 — 训练自编码器

```
输入: 768d CLIP 视觉特征
编码器: 768d -> 256d -> HIDDEN_DIM (压缩)
解码器: HIDDEN_DIM -> 256d -> 768d (重建)
损失: MSE(原始特征, 重建特征)
训练数据: 全部训练集视觉特征（自监督，无需标签）
```

### Step 2 — 计算重建误差

对每帧计算重建误差的 L2 范数：
```python
error[i] = MSE(reconstructed[i], original[i])
```

### Step 3 — 按误差排序采样

选重建误差最大的 Top 10% 帧作为核心集。

|------|---------|-----------|------|
| 随机基线 | 0.007229 | — | — |
| 冗余分布 v1.1 | 0.003961 | ↓45.2% | ✅ |
| **AE 重建误差 (128d)** | **0.007292** | **↑0.9%** | ❌ |

**关键发现**：

## 分析

### 为什么基础版失败？

#### 原因一：CLIP 特征本身高度规整

CLIP ViT-B/32 的视觉特征已经是经过大规模预训练压缩后的抽象表示：
- 每一维都经过精心学习，冗余度极低
- 768 维并非原始像素，而是语义空间中的坐标
- 小型 MLP 自编码器可以轻松学习这些坐标的线性/非线性映射

#### 原因二：数据集视觉变化范围有限

50 个 episode 都是"transfer cube"同一任务：
- 场景固定（仿真环境）
- 物体固定（同一个方块）
- 动作脚本固定（接近→抓取→转移→放置）
- AE 只需要记住少数几种视觉模式就能完美重建

#### 原因三：128d 隐藏层对于这个数据太大

压缩比只有 768:128 = 6:1。对于 16000 帧、视觉模式有限的数据集，128d 的表征能力已经绰绰有余。AE 几乎"记住"了所有帧，重建误差趋近于零。

### 与 v1.1 的对比

| 维度 | v1.1 冗余分布 | AE 重建误差 (128d) |
|------|-------------|-------------------|
| 核心机制 | K-Means 空间聚类 | MLP 自编码器重建 |
| 信息利用 | 几何位置（到簇中心距离） | 压缩质量（重建误差） |
| 在这个数据集上 | **有效**（区分度好） | **失效**（区分度极差） |
| 失败原因 | — | AE 过强，所有帧重建完美 |

### 改进方向

要增加重建误差的区分度，有三种策略：

| 策略 | 原理 | 预期效果 |
|------|------|---------|
| **减小隐藏层**（64d/32d/16d） | 强制更强压缩，部分帧无法完美重建 | 中等 |
| **去噪自编码器**（输入加噪声） | 训练 AE 恢复干净输入，难恢复帧 = 信息丰富 | 较高 |
| **变分自编码器（VAE）** | 用 KL 散度 + 重建误差的联合指标 | 较高 |
