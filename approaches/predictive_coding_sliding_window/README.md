# 思路六：滑动窗口自回归预测编码 (Predictive Coding Sliding Window)

## 核心假设

大脑本质上是一个预测机器。神经元持续对世界进行前向预测，只有当感官输入打破预测时才会产生显著的信号更新。预测编码理论（Predictive Coding）认为：**预测误差小的帧 = 大脑已经学会的模式 = 时序冗余**。

与思路二（动作变化率事件边界）的区别：
- **思路二**：用相邻帧差分 $\delta(t) = \|a_t - a_{t-1}\|_2$ 检测突变，本质上是"一阶差分"
- **本思路**：用滑动窗口历史动作训练线性回归模型预测当前帧，计算**预测残差**，是真正的"自回归预测"

## 算法设计

### 输入
- `actions`: (N, 7) 单臂 7DoF 动作序列
- `episode_indices`: (N,) 每帧所属 episode 编号

### 核心流程

```
对每个 episode:
    1. 构造滑动窗口特征：
       X[t] = flatten(actions[t-window : t])  # (window * 7,) 历史动作窗口
       y[t] = actions[t]                       # (7,) 当前帧动作目标
    
    2. 线性回归拟合：
       w = argmin ||Xw - y||^2                # 最小二乘解
    
    3. 计算每帧预测残差：
       residual[t] = mean((X[t] @ w - y[t])^2)
    
    4. 前 window 帧无法计算，设为高值保留

全局排序：选择 residual 最大的 target_size 帧
```

### 关键设计
- **Episode 内独立拟合**：避免跨 episode 泄露时序模式
- **线性模型容量有限**：过拟合风险低，残差大小仍能反映可预测性
- **前 window 帧保护机制**：无法预测的帧默认保留（设为 1e6）

## 实验结果

### 版本1：单尺度 (window=5)

| 指标 | 数值 |
|------|------|
| Test MSE | **0.005688** |
| Test MAE | 0.0409 |
| 训练帧数 | 1,600 (10%) |
| 测试帧数 | 4,000 (20%) |
| Episode 覆盖 | 40/40 (100%) |

### 版本2：多尺度融合 v1（未归一化，直接取max）

| 指标 | 数值 |
|------|------|
| Test MSE | **0.007194** ❌ |
| 说明 | 比单尺度还差，接近随机基线 |

**失败原因**：三个尺度的残差范围差异巨大（window=3: 0~0.0005, window=10: 0~0.057），直接取max导致 window=10 完全主导融合结果，window=3/5 的信号被淹没。

### 版本3：多尺度融合 v2（归一化后取max）

| 指标 | 数值 |
|------|------|
| Test MSE | **0.006734** |
| 说明 | 比v1好，但仍不如单尺度 |

**分析**：对每个尺度独立做 min-max 归一化后再取 max，消除了量纲差异。但三个尺度的残差信号高度相关（都是同一套动作数据的不同窗口），融合没有带来新的信息增益。

### 版本4：方案C — 预测误差 × 动作变化率联合

| 指标 | 数值 |
|------|------|
| Test MSE | **0.005963** |
| 说明 | 比单尺度差，变化率主导了融合结果 |

**失败原因**：
1. 残差范围（0~0.0015）和变化率范围（0~0.15）相差 100 倍
2. 归一化后相乘，变化率主导了联合得分
3. 残差和变化率不是互补信号，而是**相关信号**——变化率大的帧残差通常也大
4. 结果本质上变成了"动作变化率加权采样"，而变化率本身效果极差（0.008871）

**教训**：联合得分的前提是两种信号**正交互补**。如果两种信号高度相关，相乘只会放大噪声。

### 与基线对比（最终取最优单尺度）

| 方法 | Test MSE | vs 随机基线 |
|------|---------|------------|
| **密度过滤 FPS** | **0.003792** | **↓47.5%** |
| 自适应聚类 + PCA | 0.003835 | ↓47.0% |
| 分层融合 cr2.0 | 0.004004 | ↓44.6% |
| **预测编码滑动窗口（单尺度）** | **0.005688** | **↓21.3%** |
| 多尺度融合 v2（归一化） | 0.006734 | ↓6.8% |
| 多尺度融合 v1（未归一化） | 0.007194 | ↑0.5% ❌ |
| 随机基线 | 0.007229 | — |

## 结果分析

### 成功之处

**预测编码确实有效**。滑动窗口自回归预测误差能够区分时序冗余帧（残差小）和高价值帧（残差大），Test MSE 0.005688 显著优于随机基线 0.007229（降低 21.3%）。这证明了"可预测性"作为一个冗余度量标准是合理的。

与思路二（动作变化率差分，MSE 0.008871）相比，本思路的提升是巨大的：
- 思路二只利用了相邻帧的一阶信息
- 本思路利用了 window=5 的历史动作上下文，通过线性回归建模了动作的时序依赖关系

### 局限与失败原因

**1. 预测误差区分度不够高**

单任务数据集（"接近 → 抓取 → 转移 → 放置"）的动作模式非常规律。线性回归在 5 帧窗口内很容易拟合出稳定的预测关系，导致大部分帧的预测残差都很小，真正"打破预测"的帧很少。残差分布高度集中在低端，导致核心集选择时区分度不足。

**2. 线性模型的容量限制**

本思路使用线性回归拟合窗口动作到当前动作的关系。对于简单重复的动作模式，线性模型足够；但对于复杂的非线性动作转换（如抓取到转移的过渡），线性模型无法捕捉，导致这些关键转换帧的残差被低估。

**3. 与视觉特征脱节**

本方法仅使用动作序列计算预测误差，没有利用视觉特征。然而，动作预测困难的根本原因往往在于视觉状态的复杂性（如遮挡、光照变化），而这些信息无法从纯动作序列中推断。

## 改进实验记录

### 多尺度融合实验（已尝试）

**动机**：单一窗口只能捕捉一种时间尺度的模式。window=3 捕捉快速突变，window=10 捕捉长期趋势，融合后应该更全面。

**v1（失败）**：直接取三个尺度的残差最大值。
- 结果：MSE 0.007194，比单尺度还差
- 原因：window=10 的残差范围比 window=3 大 100 倍，融合被 window=10 完全主导

**v2（部分改善）**：每个尺度独立 min-max 归一化后再取最大值。
- 结果：MSE 0.006734，比v1好但仍不如单尺度 0.005688
- 原因：三个尺度的残差信号高度相关（都是同一套动作数据的不同窗口），融合没有带来信息增益

**教训**：多尺度融合的前提是不同尺度能提供**互补信息**。但在单任务、高重复性的数据集上，不同尺度的残差分布高度相关，融合反而引入了噪声。

### 改进方案（未来方向）

**改进一：非线性预测模型**
用小型 MLP 或 LSTM 替代线性回归，提升对复杂动作转换的建模能力。预期残差区分度会更高，核心集质量提升。

**改进二：视觉-动作联合预测**
将视觉特征（CLIP 768d）与历史动作拼接作为输入，预测当前动作。视觉信息能帮助模型理解"为什么这个动作难预测"，从而更准确地识别高价值帧。

**改进三：自适应窗口大小**
当前固定 window=5。不同 episode 长度不同，动态调整窗口大小（如 episode 长度的 1/5）可能更鲁棒。

**改进四：残差分布感知的采样策略**
当前直接按残差排序取 Top-K。可以引入分位数阈值（如只取残差 > 90% 分位数的帧），避免残差分布过于集中时选到低价值帧。

## 核心结论

滑动窗口自回归预测编码是一个**理论上合理、实践上有效但效果有限**的时序冗余定义。它证明了"可预测性 = 冗余"这一假设在机器人模仿学习中的适用性，但受限于单任务数据集的动作规律性和线性模型的表达能力，未能达到分布冗余和几何覆盖冗余的精度水平。

**四次改进尝试的否定性验证**：
- 多尺度融合：信号相关，无信息增益
- 预测误差×变化率联合：信号相关，变化率主导引入噪声
- **单尺度 window=5 是这个数据集上的最优配置**

这一结果也反过来印证了本文的核心论点——**冗余的定义必须与数据特性高度匹配**，且**融合的前提是信号正交互补**。预测编码在多任务、长轨迹、复杂动作转换的数据集上可能会表现出更强的竞争力。
