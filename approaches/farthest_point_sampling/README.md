# 思路四-A：最远点采样 (Farthest Point Sampling)

> **核心思想**：不聚类，直接贪心选"离已选集合最远的点"。每次迭代选特征空间中距离当前核心集最远的帧，直到选够 target_size。FPS 是 NP-hard 覆盖问题的贪心近似算法，能保证最大最小距离下界为最优解的 1/2。

---

## 动机

v1.1 用 K-Means 间接保证空间覆盖（稀疏簇优先），但需要预设簇数。FPS 从几何角度直接解决覆盖问题：
- 不需要预设簇数
- 天然保证特征空间中的最大覆盖
- 算法简洁，无额外超参

---

## 算法

```python
selected = [随机初始帧]
min_dists = [inf, inf, ..., inf]

for step in range(target_size - 1):
    # 计算所有帧到最新加入帧的距离
    dists = ||features - features[last_selected]||_2
    
    # 更新每个未选帧到已选集合的最近距离
    min_dists = min(min_dists, dists)
    
    # 选最小距离最大的帧（最远点）
    next = argmax(min_dists)
    selected.append(next)
```

**复杂度**：O(N x target_size)，每步一次全量距离计算。

## 实验结果

| 配置 | Test MSE | vs 随机基线 | 状态 |
|------|---------|-----------|------|
| 随机基线 | 0.007229 | — | — |
| **FPS** | **0.004294** | **↓40.6%** | ✅ |
| v1.0 固定保底 | 0.004066 | ↓43.7% | ✅ |
| v1.1 动态保底 | 0.003961 | ↓45.2% | ✅ |

**关键发现**：
- FPS 无任何启发式（无稀疏惩罚、无动态配额、无 PCA），纯几何覆盖就能达到 0.004294
- 40/40 episodes 全覆盖
- 验证了**"覆盖"本身就是核心价值**

## 分析

### FPS vs v1.0/v1.1 的递进关系

| 方法 | 核心机制 | Test MSE | 改进来源 |
|------|---------|---------|---------|
| 随机基线 | 无 | 0.007229 | — |
| **FPS** | **直接覆盖（最大最小距离）** | **0.004294** | 覆盖保证 |
| v1.0 | K-Means + 每簇1帧 + 稀疏惩罚 | 0.004066 | + 稀疏偏好 |
| v1.1 | K-Means + 动态配额 | 0.003961 | + 动态分配 |
| v1.1+PCA400 | + PCA 400d 去噪 | 0.003835 | + 噪声过滤 |

**趋势解读**：
1. **FPS 证明了"覆盖"本身的价值**：纯几何覆盖就能从 0.007229 降到 0.004294
2. **v1.0 在 FPS 基础上加了稀疏惩罚**：进一步降到 0.004066
3. **v1.1 加了动态配额**：再降到 0.003961
4. **PCA 400d 加了去噪**：最终降到 0.003835

每一步改进都是**累加的**，没有一步是多余的。

### 为什么 FPS 略逊于 v1.0？

v1.0 的 K-Means 稀疏惩罚（`1/sqrt(cluster_size)`）有意识地偏向**小簇/稀疏区域**，而 FPS 只关心**距离最大化**，不区分簇大小。在某些视觉区域，K-Means 能识别出"虽然离已选点不远，但属于一个全新的稀疏状态"的帧，FPS 则可能忽略它们。
