# 思路二：时序事件边界采样 (Temporal Event Boundary Sampling)

> **核心思想**：机器人操作由离散动作事件串联而成（接近→抓取→转移→放置）。事件边界处（动作突变）的信息价值高于稳定段。模拟海马体的事件分割理论——大脑对行为转换时刻分配更多注意力。

---

## 动机

冗余分布思路（v1.1）只利用了**空间特征**的静态分布，完全忽略了数据的**时序结构**。在机器人操作中：
- **稳定段**：机械臂缓慢移动，连续几十帧动作和视觉几乎不变 → 时序冗余
- **事件边界**：抓取、放置、松开等动作突变 → 关键教学信息

本思路独立验证：仅用时序信息（动作变化率）选择核心集，效果究竟如何？

---

## 算法

### Step 1 — 动作变化率计算

```python
δ(t) = ||A[t] - A[t-1]||₂      # 跨关节 L2 范数
```

跨 episode 边界处重置为 0，避免不同 episode 之间的虚假变化率。

### Step 2 — 事件边界检测

在每个 episode 内，用百分位数阈值找局部峰值：
- `threshold = percentile(δ, 85)`
- 局部峰值：比左右邻居都大，且超过阈值
- `min_peak_distance=5`：避免事件边界过密

### Step 3 — 分层采样

```
Layer 1: 事件边界帧保底入选
Layer 2: 每个 episode 至少保底 1 帧（变化率最高的）
Layer 3: 若不足 target_size，全局按变化率补齐
Layer 4: 若超过 target_size，保留变化率最高的帧
```

## 实验结果

| 配置 | Test MSE | vs 随机基线 | 状态 |
|------|---------|-----------|------|
| 随机基线 | 0.007229 | — | — |
| 冗余分布 v1.1 | 0.003961 | ↓45.2% | ✅ |
| **时序事件边界** | **0.008871** | **↑22.7%** | ❌ |

**关键发现**：
- 检测到 **539 个事件边界**（占核心集的 33.7%）
- 40/40 个 episode 全覆盖
- 但 Test MSE **0.008871**，比随机基线还差

## 分析

### 为什么 standalone 时序思路效果差？

1. **空间盲区**：只选动作变化大的帧，可能集中在少数几个 episode 的密集动作区域，忽略了空间分布的均衡性
2. **噪声敏感**：操作中的微小抖动会被检测为"事件边界"，但这些抖动帧的教学价值有限
3. **缺失稳定段信息**：某些任务的"稳定执行"阶段（如匀速转移）本身也包含关键信息，被完全丢弃

### 价值与后续方向

本实验的核心价值是**否定性验证**：
> 纯粹的时序信息**不能替代**空间分布信息，但可以作为**补充维度**。

后续融合实验（空间多样性 × 时序变化率）有潜力超过单一思路。
